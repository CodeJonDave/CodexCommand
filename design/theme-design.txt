========================================
DESIGN PRINCIPLES
=================

Codex Command is not designed as a desktop theme.

Codex Command is designed as the command interface
for FCV CC-01.

Evaluation Standard:

Would this exist on a Fleet Command Vessel?

If the answer is no, it should not be added.

Core Principles:

Status > Decoration

Function > Atmosphere

Readability > Effects

Consistency > Novelty

Operational Awareness > Visual Spectacle

Information Density > Empty Space

Mission Context:

Fleet Command Vessel

Primary Responsibilities:

Command
Control
Coordination

Secondary Responsibilities:

Engineering
Analysis
Development

Design Goal:

The desktop should feel like an active command station
during mission operations rather than a themed Linux desktop.
